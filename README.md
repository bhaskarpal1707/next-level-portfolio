# Bhaskar Pal — Portfolio (minimal editorial)

A minimal, editorial portfolio built with **React 19 + Vite + Tailwind CSS v4 + Framer Motion**.
Ink-on-paper dark theme, hairline borders, numbered index rows, one amber accent.

## ✨ What's inside

| Route | Page |
|---|---|
| `/` | Home — type-led hero with role typewriter, stats rules, about + portrait, featured project index with live GitHub thumbnails, self-analytics figures |
| `/about` | About — prose, grayscale portrait, impact grid, skills index |
| `/experience` | Experience — dated resume rows (3 internships) |
| `/projects` | Projects — 26 projects, text filters, index rows with repo thumbnails |
| `/charts` | Charts — the self-analytics gallery (chord, skills, domain charts from `my-portfolio-analytics`) |
| `/education` | Education — result rows with verify links |
| `/certifications` | Certifications — issuer index rows |
| `/contact` | Contact — channel rows + direct email CTA |

Project thumbnails are pulled live from GitHub's opengraph card endpoint, so they
always reflect the current repo. The analytics charts were generated by Bhaskar's
own Python/matplotlib pipeline in the
[`my-portfolio-analytics`](https://github.com/bhaskarpal1707/my-portfolio-analytics)
repo and live in `src/assets/charts/`.

## 🗂 Editing content

**Everything lives in one file: [`src/data/portfolio.ts`](src/data/portfolio.ts).**
Projects, skills, experience, education, certifications, links, stats, and charts.

- Drop your resume PDF at `public/resume.pdf` (navbar "Resume ↗" points there).
- Drop your intro reel at `public/video.mp4` (or set `profile.videoUrl`).
- Photos: replace `src/assets/bhaskar-portrait.jpg` / `bhaskar-about.jpg`.

## 🚀 Deploying to GitHub Pages (same flow as your old site)

The app uses **HashRouter**, so deep links (`/about`, `/projects`, …) work on
GitHub Pages without any server rewrites.

1. Download the project (see "Getting the code") and build:

   ```bash
   bun install      # or: npm install
   bun run build    # or: npm run build
   ```

2. One-time: if you host under a repo sub-path (e.g. `github.io/<repo>/`),
   add a base to `vite.config.ts`:

   ```ts
   export default defineConfig({
     base: "/<repo>/",   // ← add this line
     // …rest of config
   });
   ```

   If you host at `https://<user>.github.io/` (user site root), no base needed.

3. Publish the `dist` folder — easiest with `gh-pages`:

   ```bash
   bunx gh-pages -d dist -t true
   ```

4. On GitHub: **Settings → Pages → Source: Deploy from a branch → `gh-pages` / root**.

## 💾 Getting the code onto your local system

Option A — direct download: use the platform's **Download / Export** action for
this project, then unzip it locally.

Option B — push to GitHub from here and `git clone` it anywhere:

```bash
git clone https://github.com/<you>/<your-repo>.git
cd <your-repo>
npm install
npm run dev   # local dev at http://localhost:5173
```
